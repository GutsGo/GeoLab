# GeoLab · 世界地理实验室

用「抽卡」的方式认识世界：每次随机抽出一个国家或中国省级行政区，看它的地图轮廓、国旗与资料卡，再用挑战题检验记忆。

收录 **223 个国家与地区**、**34 个中国省级行政区**。纯前端应用，无需注册，学习进度保存在你自己的浏览器里。

## 开始使用

需要 Node.js 20+ 与 pnpm 10（版本已在 `package.json` 中指定）：

```bash
pnpm install
pnpm dev
```

浏览器打开 <http://localhost:3000> 即可使用。地图与资料都已内置，不需要额外的后端服务或数据库。

> 微3D 地形视图需要浏览器支持 WebGL2；英文国名朗读依赖浏览器的语音合成功能；少量图片资源需要联网加载。

## 三个视图

顶部可随时切换，也都有对应快捷键。

### 抽卡（D）

- 按 `Space` 或点击「抽取一个」随机抽一张，`←` 回到上一个；左侧地图会逐笔描绘目标轮廓并标出主要城市。
- 默认按大洲筛选（全部 / 亚洲 / 欧洲 / 非洲 / 北美洲 / 南美洲 / 大洋洲）；点「中国省区」切换到 34 个省级行政区，同样是一次一张。
- 右侧资料卡分「概览 / 历史 / 人文 / 名胜 / 美食 / 城市」六个页签；点城市可在地图上定位，「换一个」可随机换城市，国名旁可听英文朗读。
- 「对比」把当前国家与另一个国家并排比较；「索引」可搜索国家 / 首都 / 英文名并直接跳转。

### 全球（G）

- 平面地图点任意国家即可回到抽卡视图查看资料；右侧显示各大洲解锁进度。
- 右上角可切换「平面 / 微3D」：微3D 用地形起伏呈现山脉与高原，支持拖拽平移、滚轮缩放、双击复位、点击国家。风格选择会被记住。

### 挑战（C）

**世界国家**

- 「每日挑战」一天固定 10 题，完成即打卡；也可切到「自由练习」不限量练习。
- 题型为认轮廓、认国旗、找位置，答对后追问首都：认出国名得 2 分，连首都答对再 +1 分，每看一条提示 -1 分。
- 答错的国家过几题会回来重考，看过的国家隔几天也会回来复习；完成后可把当日成绩卡保存为 PNG。

**中国省区**

- 10 题一轮，认轮廓 → 认简称 → 找位置 → 识省会轮番上阵；答对得 2 分并解锁该省区资料，答错的题过几题重考。

答题时：`1`–`4` 选择答案、`H` 查看提示、`Enter` 进入下一题。

## 学习机制

| 机制 | 说明 |
| --- | --- |
| 解锁足迹 | 看过资料卡即解锁，顶栏环形进度与各大洲进度条实时更新 |
| 间隔复习 | 抽卡时按 1 / 2 / 4 / 7 / 14 / 30 天的节奏把到期国家插回抽取；答题结果也会调整复习阶段 |
| 每日打卡 | 完成当天 10 题即打卡，记录连续天数与最近两周的打卡情况 |
| 成就徽章 | 足迹收集 / 挑战实力 / 每日习惯 / 记忆深度四组，达标即弹出提示，可在「成就」中查看进度并导出成就卡 |

## 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| `D` / `G` / `C` | 切换到抽卡 / 全球 / 挑战 |
| `Space`、`→` | 抽一个（抽卡视图） |
| `←` | 上一个 |
| `I` 或 `/` | 打开索引 |
| `A` | 打开成就 |
| `Esc` | 关闭弹层 / 退出挑战视图 |
| `1`–`4`、`H`、`Enter` | 选择答案 / 查看提示 / 下一题（挑战视图） |

在输入框内打字时，快捷键不会触发。

## 数据与隐私

- 学习进度、复习记录、成就、每日打卡与地图风格都保存在浏览器 `localStorage`，**不会上传到任何服务器**；换浏览器或清理站点数据会重置。
- 需要清空时，打开「索引 → 清空学习进度」，并在 4 秒内再点一次确认。
- 国家与省区资料为学习用途整理，边界与统计以官方地图、官方数据为准。地图底图来自 world-atlas / Natural Earth，地形高程来自 AWS Open Data Terrain Tiles，均为公有领域数据。
